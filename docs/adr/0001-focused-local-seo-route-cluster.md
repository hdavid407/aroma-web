# Focused local SEO route cluster

**Status:** accepted

The site will use a small, browseable set of intent-specific pages for dining, nightlife, visits, reservations, FAQs, and group dining, plus confirmed event detail pages. We explicitly reject automated neighborhood landing pages because they would add maintenance cost and doorway-page risk without giving guests a more useful destination.

## Consequences

Every indexable route must answer a real visitor question and be maintainable from the approved content source. New event URLs are allowed when an event is confirmed, but expired event pages leave the sitemap and generated output during the next build.
