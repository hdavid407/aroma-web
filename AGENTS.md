# Project Agent Guidance

For Aroma event-poster work, use the repo-local **Aroma Poster Director** bundle:

- Skill instructions: `agents/aroma-poster-director/SKILL.md`
- Conversational agent prompt: `docs/aroma-poster-style/agent-prompt.md`
- Frozen design audit: `docs/aroma-poster-style/style-profile.md`
- Site visual references: `docs/aroma-poster-style/site-references/` — use `live-site-*.png` as the current primary evidence; older `site-*.png` captures are historical.
- Explicitly approved poster references: `docs/aroma-poster-style/approved-posters/`

Read the style profile and agent prompt before creating or revising poster concepts. Do not re-audit the site unless the user explicitly requests a style refresh. Do not promote a draft to the approved-reference set without the exact phrase “Approve this as a reference.”
